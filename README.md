# ☁️ Cloud Library Application

**Course project:** Cloud-based web service for WinForms library system using .NET  
**Description:** A cloud/web service extension of a Win-based library system, replacing local connections with web services for business logic and data access.

## 📌 Overview

This project extends a previous WinForms library system by implementing a **web service layer**.  
The application allows students and staff to interact with library data securely, with all CRUD operations (Create, Read, Update, Delete) handled via web services.
