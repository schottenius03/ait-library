# ☁️ Cloud Library Application

**Project Overview:** A cloud architecture solution that modernizes a desktop application by integrating secure web services for business logic and data distribution.  
**Tech Stack:** .NET, C#, Web Services, WinForms, SQL

## 📌 Overview

Cloud Library Application focuses on migrating local application structures into distributed web environments. By replacing direct desktop database connections with a dedicated web service layer, the system enables users to interact with enterprise library data securely. The application handles all core operations through centralized web services, ensuring decoupled data management and scalable service distribution.

## Technical Implementations

* **Service Layer Migration:** Successfully abstracted business logic from a desktop interface into distributed web services.
* **Data Management:** Full implementation of secure data operations to handle user and inventory records efficiently.
* **Architecture Modernization:** Transitioned a local architecture into a cloud ready system, focusing on data access security and decoupled service components.
